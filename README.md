# Machine Learning Concepts

Jupyter notebooks that build classic ML algorithms in NumPy and PyTorch, such as regression, trees, SVM, Naive Bayes, k-means, PCA, an RNN and a recommender. ML-Concepts is the newer, larger version of this collection.

## What's inside

- `notebooks/` has one folder per topic
- `data/` holds the small datasets and diagrams the notebooks use

## How to run

```bash
pip install -r requirements.txt
jupyter notebook
```

Use Python 3.12 or older, which torchtext needs.
